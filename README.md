# Clover Park Quest white-box demo

Unity 6 browser export for Ronald Lethcoe’s faculty preview on October 16, 2026.

Play with WASD/arrows, E to talk, 1–3 or arrows/E for choices, B for the binder, K to save, L to load, and N for a fresh quest.

Prototype dialogue and program details await faculty review. This repository contains the playable browser export, not the Unity project or private production notes.
